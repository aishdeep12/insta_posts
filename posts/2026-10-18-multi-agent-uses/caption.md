## Caption

One AI agent can do a lot. A team of them can do things one can't.

Four real uses of multi-agent systems, swipe through:

1. Engineering: a planner, a coder and a reviewer split the work and check each other.
2. Research: several agents search different sources in parallel, then one merges the results.
3. Support: a triage agent routes each request to the right specialist.
4. Operations: agents detect, diagnose and propose a fix, and a human approves it.

The rule of thumb: start with one agent, and add more only when the work splits into clear roles. More agents means more cost and more to debug.
